# Her Journey — Cinematic Life-Journey Website for Mummy

An emotional, cinematic, interactive digital storybook website celebrating Mummy's life journey (**"HER JOURNEY — Before she became my Mummy, she was a little girl with a story."**).

---

## 🌟 How to View the Website

Open **[http://localhost:3000](http://localhost:3000)** in any web browser, or double-click `index.html`.

Click the **"📷 Live Photo Swapper"** button in the top-left corner of the website to select photo files directly from your device and preview them live in real-time!

## ✨ Key Features & Effects Built
- **Winding Zig-Zag Journey Path**: Hand-drawn S-curve road SVG path weaving left -> right -> left -> right across the screen with glowing checkpoint nodes.
- **Environmental Particle Modes**:
  - Soft floating dust motes (Birth, 1999, 2007, Today)
  - Gentle white flower petals drifting down (Loss chapters)
  - Flying bird silhouettes across the sky (College & Tomorrow)
- **Wooden Table Memory Scene**: Chapter 11 photo gallery styled as printed polaroids lying on a sunlit wooden table.
- **Volume Shifts**: Automatic soft audio volume reduction during Chapter 12 (2016).
- **Exact Greeting**: **"HAPPY BIRTHDAY, MUMMY ❤️"**.
